### Featured Project: Jobzy-Agent

An AI-powered job-search assistant I’m building to help organize opportunities and evaluate how well a job matches my experience.

**Working today**
- Accepts a pasted job description through a form.
- Extracts structured job requirements using an AI model.
- Retrieves my master résumé from Google Drive.
- Compares the job requirements with résumé evidence.
- Saves the assessment, including strengths and gaps, to PostgreSQL.

**In development**
- Duplicate detection with options to review or reevaluate an existing job.
- A dashboard for reviewing assessments and tracking application status.
- Tailored résumé generation with human approval.

**Built with:** n8n, PostgreSQL, Docker, OpenAI API, and Google Drive API.
